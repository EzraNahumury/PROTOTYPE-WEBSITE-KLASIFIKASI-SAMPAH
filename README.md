# PROTOTYPE-WEBSITE-KLASIFIKASI-SAMPAH


# 🌱 Prototype Website Klasifikasi Sampah

Proyek ini merupakan prototype website untuk **klasifikasi sampah berbasis Machine Learning** menggunakan model TensorFlow Lite.  
Website ini dibangun dengan **Flask** sebagai backend, serta mendukung upload gambar untuk diprediksi kategorinya.

---


## ⚙️ Teknologi yang Digunakan
- **Python 3.x**
- **Flask** (Web Framework)
- **TensorFlow / TensorFlow Lite**
- **HTML, CSS** (Frontend)
- **Jupyter Notebook** (Eksperimen model)
